# Publication-support archive scope

RC3 supersedes the RC1/RC2 executable-pipeline gate. The current deliverable is a transparent publication code archive plus final source-table provenance package. Archive readiness does not certify raw-to-figure execution.

COMPLETE_SOURCE_TABLE_ONLY means exact final numerical source tables are included, source hashes and relevant analysis context are documented, but the exact original production script/run is not uniquely certified. DISPLAY_ONLY applies to conceptual/source-coordinate displays. Neither status means executable reproduction. The main-panel index covers all 41 lettered panels; supplementary source availability is recorded separately.

The manuscript claim map covers the current Abstract central results/definition/populations and all 17 Results paragraphs as 19 claim groups. Full current text is retained for checking scope; precise field/row verification is recorded in 145 NUMERICAL_SOURCE_CHECKS and 12 ADDITIONAL_CLAIM_CHECKS. This is a quantitative source check, not an independent clinical validation. Earlier audit labels are historical labels; current section placement is taken from the v3 manuscript.

The original 43 admitted aggregate tables remain byte-identical. New manuscript-facing exports remove identifiers and unnecessary cell metadata, preserving numerical strings in retained fields. FINAL_SOURCE_TABLE_BINDINGS records original and derivative hashes, removed fields and value-invariance checks. The original 59 analytical source blobs and 59 RC2 packaging copies were not modified in RC3. rc1 sanitized blobs differ from private workstation originals where rc1 sanitized paths; both identities remain documented.

Original CODEX coordinates and H&E images are not redistributed: the exact inspected coordinate-table hash and original public Zenodo record are provided for the display. Figure 3A's unresolved decorative asset is excluded, as are complete figure binaries containing it. Data are not newly licensed by the repository's MIT license. No raw expression matrix, TCR sequence, private instruction/session file or re-identification key is included.

RC2 audit files remain historical records under their original explicitly versioned names or rc2_snapshot. Their TRACE_INCOMPLETE executable criteria must not be interpreted as RC3 panel-provenance status. Current authority: MAIN_FIGURE_PANEL_PROVENANCE.tsv, MANUSCRIPT_RESULT_SOURCE_MAP.tsv, SUPPLEMENT_PROVENANCE_INDEX.tsv and the root release gate.
