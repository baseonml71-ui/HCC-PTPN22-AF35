# Limitations

- Retrospective heterogeneous public cohorts; no prospective locked-assay validation and no controlled treatment-by-marker interaction test.
- The clonotype and temporal core comes from one cohort. State adjustment attenuates clone-context contrasts. Clone-size, within-state and other components are not causal mediation estimates.
- GSE238264 supplied spatial specification context; Wu is an independent pretreatment extension. Adjacent-section CODEX provides tissue context rather than same-cell RNA/protein colocalization. Composition and topology are distinct.
- Positive clinical associations do not establish ICI specificity or individual-patient prediction; the non-ICI TACE context and comparator dependence remain relevant boundaries.
- Perturbation results are mixed/context dependent. Jurkat conditions have limited biological replication; the primary CD4 evidence uses the authors' donor-adjusted model. No uniform PTPN22-to-AF35 causal control is established.
- AF35 exact specification and creation evidence are recovered, but the original gene-by-gene reduction rule is not.
- Only one published comparator was exactly reconstructable; no landscape-wide benchmark superiority is claimed.
- This code archive is not a demonstrated end-to-end raw-data pipeline. Excluded individual-level data, historical freeze dependencies, unresolved producer mapping and missing historical environment versions limit independent execution.
